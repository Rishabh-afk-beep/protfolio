# Rishabh Ranjan Dangi — Developer Portfolio

A brutalist, high-performance developer portfolio built with React, TypeScript, Vite, Three.js, and Framer Motion.

## Features

- **Brutalist Design** — Bold typography, noise textures, electric accents
- **3D Interactive Background** — Mouse-tracking wireframe geometry via Three.js
- **Preloader** — Glitching percentage counter on first load
- **Interactive Terminal** — Type commands (`help`, `skills`, `whoami`, `matrix`)
- **Sound Effects** — Synthesized hover/click sounds via Web Audio API
- **Matrix Easter Egg** — Type `matrix` in the terminal
- **CRT Page Transitions** — Glitch effect when navigating between sections
- **Scroll Progress Bar** — Thick animated scroll indicator
- **Contact Form** — Powered by Web3Forms
- **Responsive** — Fully mobile-friendly

## Getting Started

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:8080`.

## Build

```bash
npm run build
```

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber
- Web Audio API
- Web3Forms
